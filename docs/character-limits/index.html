Character limits by platform

A character limit is only half of the answer. The other half is what the platform counts as a character, and platforms do not agree. For text made of combining marks the difference is large. These are the limits Zalgo Art uses to size a post.

The table is made from the same list the tool reads, so it shows what the tool will hold your post to. For anywhere that is not listed, choose Custom limit and type the number.

What the units mean

UTF-16 units
The count most of the platforms in the table use. Every combining mark is one unit.
Code points
One for each Unicode character. Every combining mark is one code point.
UTF-8 bytes
The size of the text when it is stored. Every combining mark takes two bytes.
Graphemes
What a reader sees as one character. A letter with all the marks stacked on it is one grapheme, which is why Bluesky's second limit, in bytes, is the one a stack of marks reaches first.
Weighted characters
X's own count, in which not every character weighs the same. The note on X below gives the weights.
Characters, as the web composer counts
Mastodon's web composer does not count the way its server does, and it is the composer that blocks sending over the limit. The note on Mastodon below gives both counts.

One post, counted six ways

This is one piece of lettering, the file examples/introducing-zalgoart.x.txt in the project, counted by the command zalgo count:

UTF-16 units                                 253
code points                                  253
UTF-8 bytes                                  494
graphemes                                     47
characters, as the web composer counts       107

The same text is a different length to each platform, so a post that fits one may be far over on another.

How far each figure was checked

Measured on the live site
The layout was measured on the live site in Chrome on macOS.
Measured in its font
Only the stacking was measured, in the platform's own font stack.
From documentation
The limit comes from the platform's documentation. Rendering was not measured.
Not verified
A best guess. Check before relying on it.

Platforms change their limits. If a figure here is out of date, open an issue.

Notes on each platform

These are the notes the tool shows beside its delivery check.

X (280)
X counts every mark as 1 and an invisible spacer as 2. Picture columns stand on ˍ, which X's own font lacks, so the system font draws the whole column and stacks it. Checked with X's fonts in Chrome, Firefox and Safari's engine on macOS. The compose box, Windows and the phone apps were not.
X Premium (25,000)
X counts every mark as 1 and an invisible spacer as 2. Picture columns stand on ˍ, which X's own font lacks, so the system font draws the whole column and stacks it. Checked with X's fonts in Chrome, Firefox and Safari's engine on macOS. The compose box, Windows and the phone apps were not. Over 280 the timeline shows only the start of the post until someone opens it, so the picture is cut there.
Bluesky
A column is one grapheme, so the 3,000 byte cap is the real limit: each mark is 2 bytes. The feed folds posts of 25 lines or more.
Mastodon
The server counts one per letter, but the web composer counts about one per three marks and blocks sending over the limit. Servers can raise the limit.
Discord
Nitro allows 4,000. Blank width taken from Discord's own font in Chrome, which the desktop app is built on. Firefox, Safari and the phone apps were not checked.
Discord Nitro
Blank width taken from Discord's own font in Chrome, which the desktop app is built on. Firefox, Safari and the phone apps were not checked.
Reddit comment
Post bodies allow 40,000.
Telegram
Telegram Desktop draws at most 2 marks per letter, so pictures only have a chance in the phone apps.
Threads
Threads does not say what it counts. If it counts bytes, each mark costs 2.
Instagram caption
Captions fold after a couple of lines until tapped.
YouTube comment
Live chat is 200 characters and rejects special characters. Comments fold after four lines until Read more is tapped.
Twitch chat
Twitch can drop a message for "too many characters that cannot be processed".
Slack
Slack asks for 4,000 and cuts text off at 40,000. Columns stand on ‧, checked on macOS only. If it comes out flat for someone on Windows, switch to ∆: coarser, but in the fallback font of both systems.
Facebook post
Comments allow 8,000.
SMS (one segment)
Marks force the 16-bit encoding: 70 units per text, 67 each when it is split.

Check a post before you send it

Zalgo Art counts the way the platform you pick does and shows the count beside the limit. Make a post with the zalgo text generator, or count any text with the command line tool.
